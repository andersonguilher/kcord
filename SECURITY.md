# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's private
vulnerability reporting ("Security" tab, "Report a vulnerability") on this
repository. Include the affected version, steps to reproduce, and the impact.

You can expect an acknowledgement within a few days. Fixes ship in the next
KCord release; credit is given unless you prefer otherwise.

## Scope

The KCord server (`server/`), the web client (`src/`), and the Windows desktop
app (`electron/`, `native/`). Never include credentials, user data, or
uploaded files in a report.
